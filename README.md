\# DevOps Git Workflow Project



\## Overview

This project demonstrates Git and GitHub version control best practices as part of DevOps Internship Task 4.



\## Objectives

\- Initialize a local Git repository and connect it to GitHub.

\- Use main, dev, and feature branches.

\- Track changes with meaningful commits.

\- Use pull requests to merge branches.

\- Configure a .gitignore file.

\- Create a version tag.

\- Document the workflow and Git concepts using Markdown.



\## Tools

\- Git

\- GitHub

\- Windows Command Prompt

\- Notepad



\## Branching Strategy

\- `main`: Stable project version.

\- `dev`: Integration branch for completed features.

\- `feature/\*`: Branches for individual changes.



\## Workflow

1\. Create and commit project files.

2\. Push the main branch to GitHub.

3\. Create and push the dev branch.

4\. Create a feature branch from dev.

5\. Commit and push feature changes.

6\. Open a pull request from the feature branch to dev.

7\. Merge dev into main through a pull request.

8\. Create and push the `v1.0.0` tag.
